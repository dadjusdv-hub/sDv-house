# sDv.house

Plateforme web moderne de location immobilière sans commissionnaire pour étudiants et familles.

## À propos
sDv.house met en relation directe les propriétaires et les locataires (étudiants ou familles) pour éliminer les frais d'agence superflus.

## Fonctionnalités
- Interface épurée et responsive (mobile-friendly).
- Recherche simplifiée de logements.
- Présentation claire des annonces (prix, description, type de bien).

## Technologies
- HTML5 / CSS3 (Design natif)
